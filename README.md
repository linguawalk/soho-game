# SOHO Game

한 달 단위로 진행하는 1인 경영 시뮬레이션. 판매업, 서비스업, 제조업 중 하나로 시작해 사업 방식과 장소를 바꾸고 업종을 전환할 수 있습니다. 턴 제한은 없습니다.

정적 HTTP 서버로 이 폴더를 제공하고 index.html을 엽니다. Node.js에서 `node --test`로 엔진을 검증합니다.

업종, 판매 방식, 사업장, 월별 사건은 data.mjs에서 수정합니다. engine.mjs는 정산을, app.mjs는 화면과 브라우저 저장을 담당합니다. 통화는 원화이며 수치는 게임용입니다. 초판에서는 주문을 월별로 정산하고, 미처리 수요는 다음 달로 이월하지 않습니다. 판매 및 제조 재고는 업종 전환 시 장부가의 절반에 처분합니다.
