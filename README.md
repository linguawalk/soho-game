# SOHO Game

판매업·서비스업·제조업 중 하나에서 시작하는 브라우저 경영 시뮬레이션입니다. 품목, 영업 채널, 가격 유형과 사건 대응을 복수로 조합합니다. 할인율, 할인 판매 비중과 주요 비용률은 직접 입력하며, 30일 차에 네 가지 재무제표를 작성합니다.

정적 HTTP 서버가 이 폴더를 제공하면 index.html로 시작합니다. Node.js에서 `node --test`를 실행해 엔진을 검증합니다. main 변경을 검사한 뒤 GitHub Pages에 자동 배포합니다.

- daily.mjs는 품목과 채널, 30개 사건, 일간 정산 및 월말 회계를 담당합니다.
- daily-app.mjs는 경영 입력, 저장·이어하기와 월간 보고서를 표시합니다.
- 비용 기준과 대출 조건은 게임용 가정입니다. B2B 판매대금은 다음 달에 수금하며, 일간 상품·재료 원가는 거래 단위로 처리합니다.
- 이전 월간 버전의 저장은 같은 월 1일로 변환합니다. 기존 재고는 장부가로 현금화하고 기존 보증금, 월세와 미지급 비용을 이월합니다.

생활소품의 정상가 기본값은 19,000원이며, 사입 단가는 12,000원입니다. 직접 제작은 개당 7,000원이고 회당 최소 1,000개를 선결제합니다. 회당 물류비 기본값은 300,000원이며 편집할 수 있습니다. 제작 재고는 판매할 때 매출원가로 인식합니다. 채널별 고정 직원 수는 당월 최대 배치 인원으로 월급을 정산합니다. 부가세는 매출에 별도 부과하여 월말에 정산하는 게임 규칙이며 매입세액 공제는 계산하지 않습니다.
